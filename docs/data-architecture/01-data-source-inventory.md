## Availability and boundaries

Configuration names were inspected, but this assessment did not connect to MongoDB, Redis, or D365FO. Runtime collection contents and deployed constraints are unknown. The workspace includes a local D365FO EDMX/CSDL snapshot and X++ customization table metadata; both are static code artifacts, not live verification of the current environment or a complete physical SQL schema export. No SQL database connection/migration set for the middleware, PostgreSQL, Dataverse solution metadata, object storage, or local database in the bank-mapping app was identified. Scope includes the D365FOMiddleware backend/frontend, adjacent `SDDDFO` customizations, and the `bank mapping` workbook app; other operational exports at workspace root are not application schemas.
